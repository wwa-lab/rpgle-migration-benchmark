# 评审侧材料

此目录不得交给被测模型，也没有打入两个模型侧 ZIP。

- `rubric.md`：评分办法与证据使用规则。
- `evidence-checklist.md` / `.json`：20 项来源定位和 100 个计分点，依据冻结材料建立的静态评审草案。
- `transformation.json`：开发源码到输入源码的逐文件变换、注释位置及两侧校验值。
- `source-static-checks.json`：生成阶段结构检查快照，不是业务测试通过证明。
- `baseline-manifest.json`：需求、设计、规格及开发源码的来源校验值；源文档仍保存在工程的 docs/ 和 src/，没有复制进模型输入。

源码位置使用 input 的物理行号。注释去除保持一行对一行，所以此版本开发源码和输入源码的行号相同；下一版本必须重新核对。

本参考不是外部专家独立验证的标准答案，也没有实际业务运行依据。评分时必须打开引用范围核验；发现实际代码问题或源文档差异，应认可有证据的问题报告，不能要求模型复述原需求。
