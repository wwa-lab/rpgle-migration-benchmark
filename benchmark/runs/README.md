# 运行与比较办法

此处仅有空白记录模板，没有执行任何模型评测。目标是比较相同可见材料及工具能力下的静态分析表现；耗时另记，不作为代码理解分数。

## 1. 先核定共同条件

1. 两端使用同一个 RPGFLOW-1.0 材料版本，校验所选 ZIP 和文件清单。
2. 默认采用 RO-FILES：两边均有同等的列文件、文本检索、按行读取能力，并能记录和限制调用。外网端没有这些能力时，两边一同改用 TEXT-PARTS，关闭全部工具。
3. 记录实际模型标识／版本、平台、推理设置、上下文窗口、输出上限；本地部署另记量化、运行引擎和硬件。用户此前提到的模型名称只放在配置备忘中，不作为实际运行证据。
4. 预先选择两边都能承受的上下文及输出限制。必须容纳完整材料、提示词、工具定义／历史和输出余量；字符数不等于 token 数。不得为某一边单独删文件、缩短主程序或追加上下文。
5. 关闭额外技能、检索库、网络、记忆和其他模型。每次使用新的空白会话／独立目录，只暴露模型侧材料；不要在整个开发仓库里启动被测会话。
6. 先核对文件读取与日志能力，不解答题目。任一共同条件无法满足时，受控比较记为“未就绪”；可另做探索性运行，但不得与受控结果混为一组。

Copilot 与本地部署可能含有不同的隐藏系统提示、路由或无法观察的压缩。无法核实的条件应写 unknown。只有可见条件相同时也不能声称已经排除了所有平台差异；结果标题应写“指定平台与配置下的静态分析表现”。

## 2. RO-FILES 的固定操作

- 解压 `RPGFLOW-1.0-files.zip`，只向被测会话开放 `input/`。
- 发送包内 `prompts/run.md` 的完整文本，不自行补充提示。该文件已经顺序拼接工具协议与共同任务。
- 允许的工具能力与上限：列文件、检索、按行读取；总计 200 次调用，单次读取最多 500 行，单次搜索最多 200 个匹配，累计工具返回最多 1,048,576 个 UTF-8 字节。
- 工具接口可以有平台名称差异，但返回的路径、物理行号和实际文本不得经过不同的摘要、重排或智能检索。使用额外能力的运行单独标为偏离。
- 上限由执行端计量并保存日志；仅在提示词中写限制不等于已强制执行。执行端无法计量时记录未核实，该次不能标为严格受控。
- 模型自行选择检索顺序，这是观察对象。不要由操作员针对模型的薄弱点选取代码喂给它。

## 3. TEXT-PARTS 的固定操作

- 使用 `RPGFLOW-1.0-text.zip` 中的 `delivery/`，全部工具关闭。
- 先发送 `start.md`，再严格按 `index.json` 的编号发送 `parts/` 的全部文件内容，每次只发一个分段。
- 模型的中间回复只能是收到确认；不要提问、解释源码或提前点评。两端材料分段和顺序完全相同。
- 最后发送 `final.md`，开始正式分析。这个文件就是共同任务，没有额外答案提示。
- 如果某端截断、压缩后丢失材料，或无从确认完整输入，记录输入不足／条件未核实。不要从中间分段开始另开会话继续作答后声称完整阅读。

两种模式使用相同的业务材料。TEXT-PARTS 的包装标记不属于源码；引用行号按 PATH / LINES 换算。模式不同会改变取材方式，因此只能在同一模式内比较。

## 4. 回复与重复运行

- 每次保留完整初始提示、工具日志／分段发送记录、模型原始回复和最终报告，不覆盖原始输出。
- 不回答模型的业务澄清问题，不追加需求或参考答案。缺失信息由模型列为未知；执行限制按既定协议处理。
- 仅在输出被平台截断或明显未完成时，可发送固定 `continuation.md`，最多两次；逐次记录触发原因。它不包含纠错或补充证据。不允许“再检查某个规则”这类定向追问。
- 建议每组配置各做 3 次独立运行，交错运行顺序。重复数在首轮前约定，不因成绩好坏挑选保留结果。
- 推理档位使用各模型实际可设置的值并记录；不能把两个不同平台的同名档位当作相同计算预算。若额外比较档位，另开配置组。

## 5. 评分及汇总

评分人员仅收到匿名报告、冻结 input 和 reference 中的证据清单。先隐藏模型名，按 20 项、每项 5 分评分，共 100 分，四条 Flow 各 25 分。

保存每个得分点对应的答案片段和来源位置。证据不足或代码与设计有差异时，以冻结源码为准，记录裁决，不强行给合成需求当作正确答案。参考清单为静态评审草案，发现问题需统一修订版本并对两边重新评分。

分别报告四条 Flow 得分、总分、有效证据比例、明确误报、未知事项及运行偏离。多次运行展示各次值和中位数，不根据 3 次结果宣称统计显著。尚未填写的分数为空值，不代表 0 分。

实际填写 [运行模板](run-template.json) 和 [评分模板](score-template.csv)；用 [比较模板](comparison-template.csv) 汇总。
