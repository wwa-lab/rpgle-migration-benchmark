# 接口阅读说明

## 1. 输入与输出载体

接入端的原始输入保存为 INHDRPF（头）与 INDTLPF（明细）。批次参数通过 ORDRUN 的入口传入；参数位置和字段类型请直接读取 CL、RPGLE 和 DDS。

出站信息保存在 OUTBOXPF，报表载体为 DAYRPTPF。如何形成、更新、读取这些载体，以及消息和业务状态的关系，需要根据源码分析。未提供外部发送器、反馈接收器或报表展示程序。

## 2. 外部字段含义

| 输入字段 | 传入语义 |
| --- | --- |
| IHBATCH / IHSEQ | 输入信封的批次及序号 |
| IHSRC / IHREQ | 业务请求的来源及标识 |
| IHEVENT | 请求的事件名称；具体允许值从源码读取 |
| IHDAY | 请求显式指定的处理日 |
| IHARRDAY / IHARRTIME | 接入端记录的到达日期／时刻 |
| IHORDER / IHVERSION | 请求关联的订单及期望版本 |
| IHSHIP / IHRETURN / IHSETTL / IHMSG | 请求关联的发货、退货、结算或消息身份 |
| IHACTION / IHREFSRC / IHREFREQ | 请求动作及其原请求关联 |
| IHACTOR / IHREASON | 传入的操作人及原因 |
| IHNLINE | 传入的明细行数 |
| IDLINE / IDITEM / IDQTY / IDWH | 业务行号、商品、数量和仓库载体字段 |
| IDSHIP / IDSHLINE | 明细中的原发货及原发货行关联 |

这些说明不规定每个事件的必填组合、校验顺序或状态迁移。应以实际代码为依据，不把字段名称当成行为保证。

## 3. 日期、反馈及编码

日期以 YYYYMMDD 字符传入；数量、行号等输入字符的解析行为见代码。字段宽度、小数位、键、记录格式及共享参数布局由 DDS 与 COPY 给出。

外部 SETRES 类反馈里的普通 FAIL 表示对端明确报告该次业务未生效；UNKNOWN 表示尚不能确认，RETRYOK 表示核实后报告可以再次尝试。这是提供方的语义约定，核心对不同已有状态、消息身份及尝试号如何处理仍需读源码。DELIVER 是另一类送达反馈；不能仅凭相同的 OK/FAIL 文字假定两类事件有相同行为。

字符样本使用所给 DDS 的单字节字符设置；本题没有真实币种、汇率或对外支付协议。金额用于合成场景的计量。

## 4. 阅读边界

本题只有静态文本，没有实际 PF/LF 对象、日志配置、库列表、作业状态或交易记录。可以解释代码所表达的条件和写入路径；不能据此声称已验证编译、实际发送、持久化、锁或恢复效果。
