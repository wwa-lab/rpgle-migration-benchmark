# 操作及系统背景

以下均为题目提供的虚构外部背景，只补充源码没有实现的现实交互。

## 1. 角色

| 角色 | 外部职责 |
| --- | --- |
| 客服 | 通过接入端提出订单办理、变更、取消、退货或查询请求，查看回复。 |
| 仓库人员 | 通过仓储端提出分配和实际发货／实物退回相关请求，查看仓储处理结果。 |
| 结算人员 | 通过结算对端提供处理结果，参与异常核实和人工恢复。 |
| 日终操作员 | 通过调度端指定批次及处理日，发起日终工作，查看报表及待处理事项。 |

角色名称只代表业务参与方。没有提供实际登录、权限校验、交互界面或人员组织的实现。

## 2. 时点

日间请求按事件交给接入端。虚构运营约定采用连续自然日，18:00 是接单截点：首次在 18:00 及之后到达的请求由接入端归入下一处理日；重送保留原请求处理日。日终操作员在截点后组织日终工作。

分日及角色安排是外部背景，接入端实现未提供。核心收到显式处理日及批次参数；它如何校验、保留或使用这些值，应从源码判断。没有提供节假日、时区转换或定时调度配置。

## 3. 系统边界

| 外部参与端 | 已知边界 |
| --- | --- |
| 订单接入端 | 把外部请求组织成输入头／明细载体，接收业务回复。 |
| 核心处理端 | 提供本题所含 CL、RPGLE、DDS 和 COPY。 |
| 仓储端 | 提供仓储业务请求及基础资料，接收仓储相关输出。 |
| 结算端 | 接收结算相关请求，提供业务结果或核实结果。 |
| 报表／调度端 | 组织批次及日终工作，消费报表载体。 |

外部端没有随题提供程序。对接使用哪一种网络协议、消息代理、数据库同步机制或产品，均未知。文件中的出站记录不应直接解释成已经真实发送的网络请求。请从代码定位实际入口、出口、载体及内部调用，再与这些外部角色连接。
