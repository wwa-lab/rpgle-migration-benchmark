# 多仓订单处理静态分析样本

材料版本：RPGFLOW-1.0。

这是完全虚构的订单处理样本，提供 RPGLE、CLLE、DDS、COPY 以及两份必要的外部背景。只进行静态阅读；没有编译或运行记录，也没有实际交易数据。

## 材料

- [操作及系统背景](context/operations-and-systems.md)：代码之外的角色、处理时点及系统边界。
- [接口阅读说明](context/interfaces.md)：输入／输出载体、源码成员引用及日期／字符表示。
- `src/QRPGLESRC/`：RPGLE 程序和共享 COPY。
- `src/QCLLESRC/`：CL 驱动。
- `src/QDDSSRC/`：物理文件和逻辑文件 DDS。
- `manifest.json`：文件集合、校验值及源码行数。

请按统一任务提示词输出四类 Flow。源码结论需要文件名和物理行号；外部背景需要注明文档小节。没有证据的事项标为未知；背景中的角色或时点不能说成是从代码推导出来的。

文件中的空行也计入物理行号。RPGLE 保留固定列；不要因展示换行、去空格或 COPY 展开而重新编号。COPY 的引用使用源码容器／成员名，扩展名用于磁盘文件识别。
